One system, three gates.

Every destructive command must pass the same sequence: visibility, protection, and proof.

Gate 01

Measure

Maps `.next` and `node_modules` first and reports exact size and process context before anything moves.

Gate 02

Protect

Any active processes, credentials, browser profiles, and default system paths are excluded automatically.

Gate 03

Verify

Moves are recoverable and only confirmed after manifest checks and post-action integrity reporting.

The safety contract

No blanket trash empty, no recursive guesswork, no risky defaults.
